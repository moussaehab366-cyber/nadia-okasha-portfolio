# Nadia Okasha — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript. The design uses a white and pink palette and includes About, Skills, Projects, Education, and Contact sections.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — layout, white/pink theme, responsive breakpoints, and component styles
- `script.js` — mobile navigation behavior and automatic footer year

## Run locally

1. Extract the project folder if you downloaded the ZIP.
2. Open `index.html` in a browser.
3. For editing, open the folder in Visual Studio Code. You can use the Live Server extension if you want automatic refresh while editing.

No build tools or package installation are required.

## Personalize before publishing

- Replace `hello@example.com` in `index.html` with Nadia's real email address.
- Update the education and skill details to match the real CV.
- Replace the sample project descriptions with completed projects. The three project cards are visual examples, not claims of completed work.
- Add links to GitHub, LinkedIn, or a CV if available.

## Publish with GitHub Pages

1. Create a GitHub repository named `nadia-okasha-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In the repository, open **Settings → Pages**.
4. Choose the main branch and the root folder, then save.
5. Open the published URL shown in the Pages settings.
